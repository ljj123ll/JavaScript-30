### 1. `data-key`：自定义数据属性

`data-key` 是 HTML5 引入的**自定义数据属性**（custom data attribute）的一种，用于在 HTML 元素上存储页面或应用程序的**私有自定义数据**。

它的命名规则是：以 `data-` 为前缀，后面跟随自定义的名称（这里的 `key` 就是自定义部分，也可以是 `data-id`、`data-value` 等）。

**特点和用途**：

* 不会影响元素的默认表现（无内置样式或行为），仅用于存储数据。
* 主要供 JavaScript 访问，方便在不破坏 HTML 语义的前提下，为元素附加额外信息。
* 命名灵活，只要遵循 `data-*` 格式即可。

### 2. `<kbd>`：键盘输入语义标签

`<kbd>` 是 HTML 的**语义化标签**，用于表示**用户输入的内容**，通常是键盘按键、语音命令或其他输入设备的输入。

**特点和用途**：

* 浏览器默认会以「等宽字体」显示其内容（类似代码字体），以示与普通文本的区别（可通过 CSS 自定义样式）。
* 强调内容的「输入属性」，提升文档的语义化和可读性，尤其适合技术文档、快捷键说明等场景。
